# JavaFX Pizza Ordering System Application

## Description

This project is a JavaFX desktop application for placing pizza orders.
It provides a graphical user interface where users can enter customer
information, customize pizza, and get order details.

## Features

- Customer information
- Pizza topping selection
- Pizza/order receipt
- JavaFX tabs for organizing information
- Images and application logo
- Interactive buttons and controls

## Technologies Used

- Java
- JavaFX
- Eclipse
- Git
- GitHub

## Project Structure

- src/ - Contains the Java source code
- images/ - Contains images used by the application
- README.md - Project documentation

## How to Run

1. Clone this repository.
2. Open the project in Eclipse.
3. Make sure JavaFX is configured.
4. Run the main JavaFX application class.
